### This tool no longer exists...

SnapMemories was a web application that allowed users to download their Snapchat memories securely and privately. The application was designed to offer a fast and smooth experience, while respecting user data privacy.

But today, Snapchat has implemented an official download for your memories (and one that actually works this time), so SnapMemories is no longer useful. The site is still online if you want to take a look at the code or implementation, but it is no longer maintained or updated. It remains open-source, if you're interested.
